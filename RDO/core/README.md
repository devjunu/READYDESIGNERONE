# RDO Core

RDO의 핵심 엔진 코드를 관리하는 디렉토리입니다.

## 폴더 구조

```
core/
├── media/              # 미디어 처리 관련
│   └── video/         # 비디오 처리
│       └── video_engine.h/.mm  # 비디오 재생 엔진
│
├── graphics/          # 그래픽스 관련 (향후 확장)
├── audio/             # 오디오 관련 (향후 확장)
└── utils/             # 유틸리티 (향후 확장)
```

## 네임스페이스 구조

모든 core 코드는 `rdo::core` 네임스페이스 하위에 위치합니다:

- `rdo::core::media::video::VideoEngine` - 비디오 재생 엔진

## 설계 원칙

1. **모듈화**: 각 기능별로 명확하게 분리
2. **확장성**: 향후 기능 추가가 용이한 구조
3. **재사용성**: 다른 프로젝트에서도 사용 가능한 독립적인 모듈
4. **유지보수성**: 명확한 네임스페이스와 폴더 구조
