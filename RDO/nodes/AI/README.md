# AI (Machine Learning Operators)

**데이터 타입**: ML 모델, 텐서, 추론 결과

## 용도
- AI/머신러닝 처리
- 이미지 생성 및 변환
- 객체 인식
- 자연어 처리

## 예시 노드
- Style Transfer (스타일 변환)
- Object Detection (객체 인식)
- Pose Estimation (포즈 추정)
- Image Segmentation (이미지 분할)
- Text to Image (텍스트→이미지)
- Super Resolution (해상도 향상)
- Face Detection (얼굴 인식)
- ML Model Loader (모델 로더)
